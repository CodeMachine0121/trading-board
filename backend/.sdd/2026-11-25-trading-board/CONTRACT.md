# Contract Traceability Matrix — Trading Board (backend v1)

Contract: PRD.md
Design map: ARCH.md
Implementation: `backend/` (Go module `github.com/CodeMachine0121/trading-board/backend`)
Oracle: Acceptance Criteria (60 scenarios) + Core Business Rules (15) + Non-Functional (5) = 80 clauses

> Ceiling: static conformance audit. Each clause's oracle was derived from the PRD alone, then the mapped
> test and the production code path were judged against it independently (Claude shadow verdict first,
> then Jev). Only tests already mapped to a clause were run, as corroboration. No new scenarios were
> executed by this audit.

Two Jev runs: run 1 used single-function code references; it surfaced 3 shallow/mis-asserted tests and a
misleading message (fixed in commit f69b623) and several verdicts caused by references too narrow to trace
(e.g. `walkBudgets` without `bookOf`). Run 2 (this matrix) passes the whole code path of each clause. Run 1
results are summarised in the notes.
